Under normal circumstances, attribute-value pairs set in a query will be
set in the response, too. As such, everything marked as mandatory in queries
should be considered mandatory in the accompanying responses.

Several modules don't perform any authentication checking and leave
the AV_A_RESULT value alone, unless an error occured. AV_A_RESULT is
then set by the auth module, which evaluates the AV_A_DBPASSWORD (which
has to be set by one of the lower modules). To be more specific:
